# Awesome Enterprise AI Agents [\![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A curated list of enterprise-grade AI agent platforms, frameworks, tools, and resources for production workflows.

AI agents are autonomous systems that complete multi-step business tasks end-to-end — unlike chatbots that only respond to individual prompts. This list focuses on agents built for real enterprise use: coding, reasoning, content production, research, and workflow automation.
